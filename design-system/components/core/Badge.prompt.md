One-line: Small status pill for signal sides, strategy tags and live states.

```jsx
<Badge variant="success">LONG</Badge>
<Badge variant="danger">SHORT</Badge>
<Badge variant="accent">ML Ensemble</Badge>
<Badge variant="info">Paper</Badge>
```

- **variant**: `default` `success` `danger` `warning` `info` `accent` — subtle tinted background + matching text, full-radius.
- Uppercase signal labels are conventional (`LONG`/`SHORT`); pass uppercase text yourself.
